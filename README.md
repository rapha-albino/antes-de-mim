# Antes de Mim

Site editorial do livro *Antes de Mim*, de Raphael Albino.

O projeto prolonga a conversa aberta pelo livro sobre ancestralidade, raça, trabalho, pertencimento, vulnerabilidade e o esforço de existir inteiro.

## Desenvolvimento

Requer Node.js 22 ou superior.

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
